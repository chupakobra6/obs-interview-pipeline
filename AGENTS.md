# OBS Interview Pipeline

- Действующий контракт и команды — в `README.md`; читать нужный раздел, без обязательного Project Loop.
- ASR реализован в соседнем Telegram Harvest. При изменении общего контракта синхронно менять обе стороны и проверять их совместимость.

- Пояснения писать по-русски; точные команды, имена API и цитаты сохранять.
